# Pankaj Kumar — Personal Website

GitHub Pages-ready personal website for Pankaj Kumar, focused on quantitative finance, risk management, statistical modeling, copulas, time-series analysis and machine learning.

## Deploy on GitHub Pages

1. Create a GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html` and `style.css`.
3. Upload your CV PDF and name it `Pankaj_Kumar_CV.pdf`, or change the filename in `index.html`.
4. In GitHub: Settings → Pages → Deploy from branch → `main` / root.
5. Replace the placeholder LinkedIn, Google Scholar and GitHub URLs in `index.html` with your actual profiles.
